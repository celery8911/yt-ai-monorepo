## 🚀 快速开始

### 安装

```bash
# 使用 pnpm（推荐）
pnpm add @yt/ui

# 使用 npm
npm install @yt/ui

# 使用 yarn
yarn add @yt/ui
```

### 配置 Tailwind CSS

在你的项目中配置 Tailwind 扫描组件库：

```javascript
// tailwind.config.js
export default {
  content: [
    "./src/**/*.{js,jsx,ts,tsx}",
    "./node_modules/@yt/ui/dist/**/*.js"  // 扫描组件库
  ]
}
```

### 使用组件

```tsx
import { Card, CardContent, CardHeader, Dialog } from '@yt/ui';

function App() {
  return (
    <Card>
      <CardHeader>欢迎</CardHeader>
      <CardContent>这是一个示例卡片</CardContent>
    </Card>
  );
}
```
